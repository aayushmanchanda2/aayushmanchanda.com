---
title: Build anything non-trivial in seven steps
emoji: 🏗️
summary: Grill the idea, plan, tickets, one agent per ticket, prove it, ship.
order: 3
---

Every shortcut I've tried skipped one of these steps, and I paid for it a week later.

1. **Grill the idea.** The agent restates the ask in plain English, then asks hard questions until the scope holds.
2. **Validate the plan** with parallel reviewers: one checks facts, one feasibility, one only attacks the premise.
3. **Cut tickets.** Thin slices, each shippable alone.
4. **One fresh agent per ticket.** Only one agent writes to the repo at a time.
5. **Prove it works.** "Tests pass" from an agent is a claim. I run the command and load the page myself.
6. **Run a QA loop.** Read-only reviewers check the whole diff, then one pass fixes what they found.
7. **Ship** with a README runbook, its facts checked against the source.

Skip it for a one-line fix. It's for anything bigger.
