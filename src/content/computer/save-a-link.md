Publishing only happens if saving costs nothing. If it needed a laptop, I'd have a drafts folder instead of a site.

1. On my phone, open the share sheet and choose Raindrop.
2. Pick Publish/Tools, Publish/Sites or Publish/Reading. The collection decides the section.
3. Every three hours a GitHub Actions job screenshots what's new in those collections and commits it. Vercel deploys.

In Telegram, I text the link to Hermes, an open-source agent from Nous Research. It fetches the page, writes the real title and a one-line note in my voice, and files it: a bare link to reading, "tools" or "sites" to those, any other words as tags.

Saving isn't reviewing: an untested tool says so on its page.
